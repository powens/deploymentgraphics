# deploymentgraphics

ESM-only TS library that renders 40k deployment maps as SVG, plus a demo viewer
(GitHub Pages). Domain terms (Placement, Placed, Resolve, Template box,
centre-pivot, Controls): read `CONTEXT.md` first.

## Commands (pnpm, Node >=22.6)

```sh
pnpm test                      # vitest: src/**/*.test.ts, scripts/*.test.mjs, static/*.test.js
pnpm lint && pnpm type-check   # CI does NOT type-check; run it yourself
pnpm gen:presets[:check]       # static/data/*.yml -> src/presets/*.ts
pnpm convert:40kdc[:check]     # vendored 40kdc JSON -> static/data/terrain/combined.yml
make serve                     # demo with live reload (serves static/ over dist/)
pnpm build:lib                 # publishable lib/ (tsc + scripts/rewrite-dts-extensions.mjs)
```

CI order: convert:40kdc:check, gen:presets:check, lint, test, build.

## Layout

- `src/index.ts`: published entry. Geometry/placement/svg-backend are internal, not exported.
- `src/bundle.ts`: demo entry (rollup -> `dist/bundle.js`); re-exports presets, event
  matrix, js-yaml for `static/app.js`. The viewer fetches nothing at runtime.
- `src/placement.ts`: sole owner of the centre-pivot transform
  (`placedTransform`/`placedRing`/`placedFromPin`).
- `src/viewer-controls.ts`: one row per viewer control; adding a control = one row.
- `scripts/*.mjs`: 40kdc converters + normalizer (`battlemaster-normalize.mjs`).
- `lib/`, `dist/`: build output, gitignored.

## Gotchas

- `src/presets/*.ts` with a "Generated by" header: never hand-edit. Edit the YAML
  in `static/data/`, then `pnpm gen:presets`. (`build-config.ts`, `index.ts` are hand-written.)
- `combined.yml` is generated purely from the vendored 40kdc JSON (no hand-authored
  layouts or overlays); fix bad terrain upstream, never in the vendored files.
  Refreshing terrain: use the `update-40kdc-terrain` skill.
  `make update-terrain` does NOT run `gen:presets`.
- A module loaded by a plain-node `.mjs` converter spells its relative imports
  `./foo.ts`; all others use `./foo.js` (see tsconfig.json comment).
- DOM tests opt in with `// @vitest-environment happy-dom`; the default is node.
- Layout ids are published API (`buildConfig({ layout })`): renames need a CHANGELOG entry.
- `assets/sample.svg` is tracked: `pnpm build:lib && node --experimental-strip-types
  scripts/render-sample.mjs`, then look at it.
- `docs/` is gitignored on purpose (local specs).

## Conventions

Conventional commits with scope, e.g. `refactor(viewer): ...`; the trailing `(#N)`
is the issue number.
